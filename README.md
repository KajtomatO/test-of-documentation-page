# Nimbus Docs: standalone Docusaurus documentation on GitHub Pages

A proof of concept for hosting a documentation site as its own repository:
[Docusaurus](https://docusaurus.io/) generates a static site, GitHub Actions
builds it, and GitHub Pages serves it.

**Live site:** <https://kajtomato.github.io/test-of-documentation-page/>

The content documents *Nimbus*, a fictional job scheduler. The product is
made up; everything about how the site is written, built and published is real.

## What is included

- Landing page plus a **versioned** docs section (`1.0` released, `Next` unreleased).
- Full-text **search** built into the static site, no external service.
- **Mermaid** diagrams, tabs, hints and highlighted code blocks in Markdown.
- A GitBook-inspired look (Inter, IBM Plex Mono, purple accent), implemented in one stylesheet with self-hosted fonts.
- `deploy.yml`: build and publish on every push to `main`.
- `test-deploy.yml`: build check on every pull request.

## Quick start

```bash
npm ci          # install dependencies (Node 24, see .nvmrc)
npm start       # dev server with live reload at http://localhost:3000/test-of-documentation-page/
npm run build   # production build into build/
npm run serve   # serve build/ locally (needed to try the search box)
```

## Repository layout

| Path | Purpose |
| --- | --- |
| `docs/` | Documentation source for the **Next** (unreleased) version. |
| `versioned_docs/`, `versioned_sidebars/`, `versions.json` | Frozen snapshots of released versions. |
| `src/` | Landing page and custom styling (React + CSS). |
| `static/` | Files copied verbatim to the site root (favicon, images). |
| `docusaurus.config.ts` | Site title, URL, navbar, footer, plugins. |
| `sidebars.ts` | Sidebar definition (autogenerated from the `docs/` folder). |
| `.github/workflows/` | Build and deployment automation. |
